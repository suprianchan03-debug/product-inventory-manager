# Product Inventory Manager

A simple browser-based Product Inventory Manager built using TypeScript, HTML and CSS.

## Concepts used

- Basic types: string, number, boolean-style DOM values
- Functions
- Scope using variables and function scope
- Interface for Product
- Arrays
- DOM manipulation
- TypeScript compilation

## Features

- Add products
- Display products in a table
- Calculate inventory value
- Show total products and total quantity
- Delete products

## GitHub Pages

The compiled JavaScript is stored in the `dist` folder. The page can be published using GitHub Pages.

## Compile TypeScript

```bash
tsc
```

This creates `dist/app.js` from `src/app.ts`.
